# Maïmo — site vitrine

Site statique (HTML/CSS/JS, aucune dépendance) de Maïmo, cantine & mezzés à partager, 34 rue Léon Jamin, Nantes.

- `index.html` + `main.js` : page d'accueil (mobile d'abord)
- `mentions-legales.html`, `404.html`
- `vercel.json` : en-têtes de sécurité, cache, URLs propres
- `./set-domain.sh https://domaine.fr` : renseigne le domaine (canonical, Open Graph, sitemap, robots, llms.txt)
